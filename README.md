# Vet Cancer Trial Finder — Beta

Early public-test prototype for matching canine oncology patients to potentially relevant veterinary clinical trials.

## Deploy on Streamlit Community Cloud

1. Create a GitHub repository and upload `app.py`, `requirements.txt`, and this README to the repository root.
2. Connect the GitHub account to Streamlit Community Cloud.
3. Create an app and choose `app.py` as the entrypoint.
4. Pick a memorable `streamlit.app` subdomain and deploy.

No secrets or database are required for this beta.

## Important

This is a screening tool, not medical advice and not a determination of clinical-trial eligibility. Trial status and criteria must be confirmed with the study investigators.
