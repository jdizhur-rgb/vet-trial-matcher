The complete run evidence is split into two independent ZIP archives to stay below the connector 16 MiB request limit. Unpack BOTH evidence-bundle-1.zip and evidence-bundle-2.zip from repository root before rerunning evidence-reference validators. They preserve the retrieved clinical text, actual Web/search responses, timestamps, document assessments, immutable checkpoints and command logs. Exact restrictions remain in data/source_access_restrictions.json. Accounting PASS is not clinical completeness.
